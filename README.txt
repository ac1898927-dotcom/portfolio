# Chavda Adityasinh - 3D Portfolio

A professional animated portfolio built with:
- HTML
- CSS
- JavaScript

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser.

No Django is required.

The portfolio includes a CSS 3D animated hero, responsive design, smooth scrolling, mobile navigation, skill cards, education, training, certification and contact sections.
